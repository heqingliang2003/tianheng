# 天衡

《天衡》是一部长篇架空战争小说，主线包括北疆战争、军政制度、人物成长与克制慢热的双主角感情。

当前状态：**规划阶段**。全书暂定六卷、132章，预计55—70万字。

## 正文章节命名

统一使用三位章号：

```text
第001章-临川.md
第057章-不是军报上的人.md
第132章-天衡.md
```

章节只放入所属卷目录。大纲、人物档案和账本不与正文混放。

## 写作流程

1. 从 `docs/02-写作计划.json` 读取下一章及状态。
2. 核对 `docs/01-全书大纲.md` 中该章规划。
3. 阅读上一章正文及三个 `tracking/` 账本。
4. 按 `templates/章节模板.md` 创作并自查。
5. 更新章节摘要、人物状态、战争数字与伏笔。
6. 章节通过验收后，把写作计划状态由 `pending` 改为 `completed`，填写字数。

## 硬性连续性

- 女主国家统一称为“越国”，废弃“离国”旧称。
- 临川第一场雪是十月十七，比往年早23天。
- 临川第27日前后撤城，援军第30日抵达。
- 男女主在临川期间只通过军报知道名字，绝不见面。
- 战争必须受粮草、道路、马匹、命令传递和情报误差约束。
- 配角必须有独立判断，裴昭与崔景澜不得工具人化。
